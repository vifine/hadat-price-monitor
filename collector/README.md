# Сборщик цен Hadat на российских площадках

Ежедневный сбор цен **собственных товаров Hadat** (43 SKU) на площадках РФ через Chrome пользователя
(инструменты Claude in Chrome). Логин не нужен, регион — Москва. Внутренние API площадок не используются —
читается только отрисованная страница.

## Как работает ежедневный прогон

1. **Открыть свою вкладку** (`tabs_create_mcp`), чужие вкладки не трогать.
2. Для каждой площадки — **один вызов `browser_batch`**:
   `navigate(URL)` → `computer.wait(N с)` → `javascript_exec(<сниппет из файла>)` → `get_page_text`.
   Сниппет сам прокручивает/подгружает выдачу, собирает массив офферов в `window.__offers`
   и заменяет страницу на `<pre>` со строками через `|`:
   `id|price|base_price|checkout_price|in_stock|seller|…|title`.
   Через страницу — потому что ответ `javascript_exec` обрезается примерно на 1500 символах,
   а `get_page_text` отдаёт весь текст.
3. **Сопоставить** строки с SKU по `links.json` (`source_id` + `external_id` → `sku`).
   Карточки из списка `unmatched` пропускаются. Новые `external_id`, которых нет ни в `links`,
   ни в `unmatched`, — это новые карточки: их нужно разобрать вручную и дописать в `links.json`.
4. **Записать строки** вида
   `{sku, source_id, observed_on, price, base_price, checkout_price, seller, in_stock, url}`
   (формат — как в `pilot_2026-10-20.json`). В Supabase пока не пишем: схема ждёт согласования.
5. Закрыть свою вкладку (`tabs_close_mcp`).

### Что означают цены

| поле | смысл |
|---|---|
| `price` | цена, которую покупатель платит без условий: WB — без WB Кошелька; Ozon — «с другими банками»; Lamoda — итоговая после автоматической акции |
| `base_price` | зачёркнутая цена |
| `checkout_price` | цена при условии: WB Кошелёк, Ozon Карта / «с банками». На Lamoda, в Л'Этуаль и Рив Гош — `null` |
| `in_stock` | `true`/`false`; `null` — наличие из выдачи не определить (WB) или товар «только в магазинах» (Рив Гош) |

Вспомогательные сниппеты карточек (не для ежедневного прогона — для сопоставления и проверки спорных карточек):

- `wb_card.js` — объём, продавец, цена с WB Кошельком, наличие. В одном `browser_batch` можно открыть ~10 карточек.
- `ozon_card.js` — обычная цена, цена «с банками», зачёркнутая цена, продавец.

## Файлы

- `links.json` — `links` (сопоставленные карточки: `sku, source_id, external_id, url, title_on_site, match, note`)
  и `unmatched` (наборы, уход за телом и руками, товары Hadat вне 43 SKU, чужие бренды, спорные карточки — с причиной).
  `match: exact` — линейка, тип и объём подтверждены; `probable` — есть допущение, оно описано в `note`.
- `pilot_2026-10-20.json` — пилотный прогон: `summary` по площадкам (найдено карточек, сопоставлено SKU,
  SKU ниже РРЦ, 5 худших отклонений) и `rows`.

## Известные ограничения

- **Wildberries**: в выдаче нет продавца и наличия, а цена показана без WB Кошелька. Цена с кошельком и наличие
  видны только на карточке. Товар «Нет в наличии» в выдаче всё равно показан с ценой (пример: 1580472261).
  Много перепродавцов с обезличенными названиями («Шампунь женский 250 мл масло») — они лежат в `unmatched`.
  Карточка товара иногда перезагружается в первые 1–2 с; если `javascript_exec` падает с «Inspected target navigated»,
  вызов нужно повторить.
- **Ozon**: в плитке обычно только цена «с банками / Ozon Картой» (зелёная). Обычную цену видно только на карточке
  (`ozon_card.js`, виджет `webPrice`; читается через `textContent`). Чёрная цена в плитке у кросс-бордер продавцов
  тоже может быть ценой «с банками». Ниже товаров бренда подгружаются рекомендации — `ozon.js` отсекает их по слову Hadat.
  Масло 60 мл продают 14 одинаковых кросс-бордер карточек; в пилоте открыты 2 (1 622 с банками / 1 707 без),
  у остальных 12 `price = null` и есть только `checkout_price`.
- **Lamoda**: в карточке три цены «9 014 / 6 044 / 4 230 ₽». Первые две зачёркнуты: 9 014 — `base_price`,
  6 044 — «цена до акции» (`price_before_promo` в `window.__offers`; почти всегда равна РРЦ), 4 230 — `price`.
  Из-за этого Lamoda почти целиком «ниже РРЦ» (идёт акция −30…−40 %). Мини-форматы 50 мл в выдаче
  названы обезличенно («Шампунь»): линейка взята из карточки и записана в `links.json`.
- **Л'Этуаль**: объём в плитке не показан. У многих товаров 2–3 объёма («Доступно 2 варианта»), в плитке — цена
  одного из них. Привязка сделана по совпадению цены с РРЦ (`probable`). Для цен других объёмов нужен проход
  по карточкам. Мини-форматы без цены (нет в наличии) привязаны к 50 мл по названию.
- **Рив Гош**: зачёркнутых цен нет; часть товаров «только в магазинах» (`in_stock = null`). Объём берётся из slug (`…-50`, `…-150`).
- **Золотое Яблоко**: 20.10.2026 бренд, поиск и карточка товара отдавали «упс… страница не найдена»,
  скорее всего это антибот-заглушка. Обходить её не пытались. `zya.js` — непроверенный черновик под прежнюю структуру
  (`<article>`, `textContent`, цена «от N ₽»). Цены «от» мало: это цена минимального объёма, поэтому для ЗЯ
  понадобится проход по карточкам (~3 вызова на 24 товара). Нужна проверка в браузере пользователя.
- **Hydro SPA Hair Treatment** (50/250/500 мл) продаётся на всех площадках, но среди 43 SKU его нет
  (на Lamoda своя РРЦ 3 660 / 6 113). Нужно решение: добавить SKU или игнорировать.
