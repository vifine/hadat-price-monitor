# Hadat — мониторинг цен

Этап 1: интерфейс на тестовых данных (`index.html`, один файл, без сборки).

Открыть: двойной клик по `index.html` или GitHub Pages.

Данные читаются только через `loadData()`. При подключении базы меняется только эта функция.

## Правила репозитория
- Репозиторий публичный: ключи API, токены, выгрузки с ценами конкурентов и файлы из личных папок сюда не коммитятся.
- Секреты — в переменных окружения или в хранилище секретов, не в коде.
