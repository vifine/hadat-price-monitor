# Hadat — мониторинг цен

Интерфейс мониторинга цен собственных товаров Hadat на маркетплейсах относительно РРЦ.
Один файл `index.html`, без сборки. Конкурентов в мониторинге нет.

Открыть: https://ht-price-monitor.vifine.tech/ или двойной клик по `index.html`.

## Данные

Данные читаются только через `loadData(market)` в `index.html`. При смене источника меняется только эта функция.

Источник — база Supabase (проект `hadat-price-monitor`, Франкфурт), чтение по REST:

| Таблица | Что хранит |
|---|---|
| `markets` | рынки: `ru` (RUB), `us` (USD) |
| `sources` | источники рынка: WB, Ozon, Lamoda, Золотое Яблоко, Amazon, Shopify |
| `products` | SKU и название |
| `product_rrp` | РРЦ товара на конкретном рынке |
| `price_observations` | цена SKU в источнике за день: цена продажи, базовая цена (если есть скидка), статус `ok` / `no_price` / `error` |

Состояние:
- Товары и РРЦ для России — настоящие (43 SKU).
- Цен в `price_observations` пока нет, источник цен не выбран. Пока таблица пуста, цены для России генерируются как демо, и в подвале страницы написано «Демо-цены · не из источника». Как только появятся строки, сайт сам покажет реальные цены, метка исчезнет.
- Для США РРЦ и цен пока нет, ячейки пустые.

## Доступ к базе

- Сайт читает базу публичным ключом (publishable/anon). Он публичный по устройству Supabase, поэтому лежит в коде. Что с ним можно: только `select` из пяти таблиц выше.
- Запись закрыта политиками RLS: писать могут только сервисные ключи (сборщик цен, администратор).
- Сервисный ключ (`service_role`), пароль базы и любые другие секреты в репозиторий не коммитятся. Они хранятся в хранилище секретов.
- Всё, что лежит в этих таблицах, видно любому, у кого есть адрес сайта. Не класть в них ничего, что не должно быть публичным.

## Картинки

- `swatches/<sku>.webp` — свотчи товаров 96×96, выгружены из Figma. Если файла нет, показывается цветной квадрат.
- `flags/` — круглые флаги из https://github.com/vifine/round-flags (MIT), см. `flags/SOURCE.md`.

## Правила репозитория

- Репозиторий публичный: ключи API с правом записи, токены, выгрузки с ценами конкурентов и файлы из личных папок сюда не коммитятся.
- Изменения идут напрямую в `main`.
